  wrong shape for the question. The four checks are two kinds. **Dose-match and studied-form are
  the CORE PAIR**: claims about what the bottle IS. **Independent testing and label disclosure
  are the TRUST PAIR**: claims about whether we can believe what it says about itself. The
  verdict is three-valued and derived, with no aggregation:
  - all four pass → "This bottle gives you what was studied."
  - core pair passes, either trust check fails → "Matches what was studied — but we can't fully
    verify it."

    the other three.** A 3-of-4 with a dose mismatch is a fail — the exact case a threshold got
    wrong.
  - any check null → no verdict sentence at all; the unassessed state stands.
