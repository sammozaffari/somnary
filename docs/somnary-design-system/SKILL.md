If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.
If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Non-negotiables for Somnary: focus ring lives in styles.css (:focus-visible — inline styles can't express it; never remove); --border-input (3:1) for sole-boundary borders; --sage-text for sage text (--sage is graphic-only); hit areas never below --control-md 44px; never invent a number or write an unsourced health claim in a design file (mark placeholders clearly); the bottle-verdict rule ("delivers" = 3 of 4 checks in RemedyPage.jsx) is a placeholder scoring rule awaiting a methodology owner — never copy it into a build as policy, and the four criteria are unlikely to be equally weighted; wordmark "Somnary" — capitalised, no trailing period, Onest 600; the mark is a capital S in Onest 600 in the rounded square (no motif; SVG assets are outlined paths, never live text); sentence case everywhere (buttons, labels, headings — no all-caps eyebrows); remedy names sentence case ("Melatonin", "Tart cherry") except scientific convention (L-theanine, 5-HTP, GABA, CBD, CBN, CBT-I, vitamin D); ONE type family — Onest — with deliberate weights (titles 550, headings 650, labels/buttons/card titles 600, body 400, metadata 450), no serif, no mono, no signature device; all figures tabular lining figures (font-variant-numeric: tabular-nums); dates human ("14 July 2026"), never ISO; two verdicts never merged into one score; every bucket badge carries its plain sentence; every claim carries a "See the study" chip; technical vocabulary only inside popovers; colour means data — ink blue --evidence is reserved for the evidence bar and key, never interface (buttons, links, focus are --ink; no --accent token exists); the research filter is a nested bar (track = cited, 35% evidence = measured sleep, solid evidence = verified, transparent hairline gaps at segment boundaries) with direction as a plain sentence, never a scatter; research sources are called "papers" with the noun always present ("5 of 14 papers"); the verify tier is "results we could verify", never "reported enough to check"; the muted remainder is always "didn't measure sleep", never anything implying weak evidence; a safety flag always outranks any evidence visual; brand placeholders are neutral typographic marks (no verdict tinting); named tokens only (spacing, control heights, radii — nested radii concentric: inner = outer − padding); both day and dusk themes; WCAG AA; no healthcare blue, neon, gradients, stock wellness photography, or sleep clipart.
