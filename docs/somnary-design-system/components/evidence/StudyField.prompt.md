The research filter: one nested bar — papers cited / measured sleep / results we could verify. The only saturated element on a page (`--evidence`). Copy stands alone at every size; the noun is always present.

```jsx
<StudyField counts={{ cited: 14, sleep: 9, verifiable: 5 }} helped={5} />
<StudyField size="thumb" counts={{ cited: 5, sleep: 0, verifiable: 0 }}
  safetyFlag="[Placeholder — serious safety concern wording, pending sourcing]" />
<StudyField size="share" subject="Melatonin" counts={{ cited: 14, sleep: 9, verifiable: 5 }} />
```

Captions: hero "Of 14 papers, 9 measured sleep, and 5 published results we could verify." · thumb "9 of 14 papers measured sleep; 5 we could verify" (both steps, always) · none-measured "5 papers on this remedy — none measured sleep." `variant="two"` moves the verify count to an expandable line. Never relabel the muted segment.
